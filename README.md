# 📚 EADStudent

**EADStudent** é uma plataforma de ensino a distância com funcionalidades voltadas tanto para alunos quanto para administradores. O sistema permite a gestão de cursos, conteúdos, aulas e usuários, oferecendo uma solução completa para ambientes EAD.

---

## 🚀 Tecnologias Utilizadas

### Frontend:

* React
* TypeScript
* Tailwind CSS
* React Router DOM
* Next.js (App Router)

### Backend:

* Django

---

## 📁 Estrutura do Projeto

```
EADStudent/
├── backend/            # API e lógica de servidor
└── frontend/           # Interface web (aluno/admin)
```

---

## 🔧 Como Rodar Localmente

```bash
# Clone o repositório
git clone https://github.com/SudoMaster7/EADStudent.git
cd EADStudent

# Inicie o backend
cd backend
npm install
npm run dev

# Em outro terminal, inicie o frontend
cd ../frontend
npm install
npm run dev
```

---

## 🌐 Deploy

* Backend: [Render](https://render.com/), [Railway](https://railway.app/) ou outro
